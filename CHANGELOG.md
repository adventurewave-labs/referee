# Changelog

## v0.1.0 (2026-11-23)

- Apply task-scoped policy to agent tool calls through an MCP proxy.
- Check provenance and sensitivity independently. Support policy-authorized redaction and human approval.
- Verify hash-chained decision receipts with signed batch heads and optionally export receipt metadata over OTLP/HTTP.
- Include an example policy, framework presets, and an offline policy check.
- Ship Linux x86-64 and macOS Apple Silicon binaries, source, and SHA-256 checksums under the MIT license.
